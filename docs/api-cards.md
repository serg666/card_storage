# CardStore service

[Главная](../README.md) / API по карте

<br>

## Добавить карту

**URL: `[POST] /v1/cards`**

Тело запроса отправляется в формате JSON:

```
{
    "pan": "1111 2222 3333 4444",
    "exp_date": "25/01",
    "holder": "IVANOV IVAN"
}
```

---

## Получить список карт

**URL: `[GET] /v1/cards`**

**Query параметры:**

| Параметр   | Описание                                            |
|------------|-----------------------------------------------------|
| _pan_      | PAN карты                                           |
| _exp_date_ | Дата окончания действия карты (не обязательно)      |
| _holder_   | Держатель карты (не обязательно)                    |
| _limit_    | Кол-во результатов в ответе (default: 10, max: 100) |
| _offset_   | Пропустить N строк (для пагинации)                  |

**Ответ:**

```json
{
    "data": [
        {
            "id": 1,
            "holder": "IVANOV IVAN",
            "exp_date": "25/01",
            "pan": "1111222233334444",
            "token": "ab5a61905069cf5b554ce0f7006a6469303679adde3f4233eecd38f403a57792"
        }
    ]
}
```

---

## Получить карту по токену

**URL: `[GET] /v1/cards/token`**

**Query параметры:**

| Параметр   | Описание                                            |
|------------|-----------------------------------------------------|
| _token_    | Токен карты                                         |

**Ответ:**

```json
{
    "data": {
        "id": 1,
        "holder": "IVANOV IVAN",
        "exp_date": "25/01",
        "pan": "1111222233334444",
        "token": "ab5a61905069cf5b554ce0f7006a6469303679adde3f4233eecd38f403a57792"
    }
}
```

**Ошибки:**

* `[404]` - Карта не найдена

```json
{
    "message": "Model not found"
}
```

---

## Удалить карту

**URL: `[DELETE] /v1/cards/{id}`**
